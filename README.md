---

## 📚 Описание

Данный репозиторий содержит лабораторные работы, выполненные в рамках курса по супервизорному управлению. В ходе работ изучаются основы управления роботами на примере симуляционной среды с использованием **TurtleSim**, а также моделирование дискретных систем управления с помощью **конечных автоматов** и **сетей Петри**.

## 🧪 Содержание лабораторных работ

### 1. Работа с TurtleSim (Черепашка)
- Изучение базовых принципов управления в среде ROS.
- Реализация алгоритмов движения по заданным траекториям.
- Использование супервизорного подхода для управления поведением черепашки.
- Интеграция простейших обратных связей.

### 2. Конечные автоматы (Finite State Machines)
- Разработка конечных автоматов для управления состояниями робота.
- Реализация переходов между состояниями на основе внешних событий.
- Применение конечных автоматов для последовательного выполнения задач.

### 3. Сети Петри (Petri Nets)
- Моделирование параллельных процессов с помощью сетей Петри.
- Анализ свойств сети: достижимость, активность, ограниченность.
- Использование сетей Петри для синхронизации нескольких агентов.

## 🛠️ Стек технологий

- **ROS (Robot Operating System)** — среда для разработки робототехнических систем.
- **TurtleSim** — симулятор черепашки для отработки базовых алгоритмов.
- **Python** — язык программирования для реализации узлов и скриптов.
- **Git** — система контроля версий.
